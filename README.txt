STUDY TIMER — White / Black / Green

HOW TO USE
1. Extract StudyTimer.zip.
2. Open the StudyTimer folder.
3. Double-click index.html to open the timer in your browser.
4. Choose focus, short-break, and long-break durations.
5. Press Start timer. Use Pause, Skip, or Restart as needed.

CYCLE
Focus → Short break → Focus → Short break → Focus → Long break

NOTES
- The timer is a self-contained web app; no installation or internet connection is required.
- Keep the browser tab open for the most reliable timing.
- Timer completion displays an alert and advances to the next stage.
- Restart returns to the first focus session using the selected focus duration.
